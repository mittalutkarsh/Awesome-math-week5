The addition rule

If a count can be split into disjoint (non-overlapping) cases, we count the cases separately and add.

Separate something into cases: “either ___ or ___”. Disjoint means the cases share nothing: no answer belongs to two cases.

total = (step × step) + (step × step)

Using both

Steps inside each case multiply; the cases add.

cases = the decisions that behave differently

How to choose the cases

How to choose the cases

“Cases should be made based on the idea that some cases behave differently: some decisions affect the count differently than others.”

Don’t make a case for every possibility. If the even digit of a 100-digit number could be in any of 100 places, that’s 100 cases: too many. Instead ask which decisions behave differently. The first digit can’t be 0, so it behaves differently from the other 99 places, which all behave the same. That gives just two cases: the first digit is the special one, or one of the other 99 is.

The same idea works backwards on the three-digit problem: the tens and ones places behave the same, so two cases are enough there too.

Complementary counting

Week 5, section 2. When “at least one” would need many cases, count the complement (the opposite) instead. The ones you want and the rest are two disjoint cases that make up the total, so the count you want = Total − the rest.
